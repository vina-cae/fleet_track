# Fleet Track - Parcel Management System

## Project Description
Fleet Track is a full-stack web application designed for logistics companies to manage, track, and update parcel deliveries. It features a secure admin dashboard with real-time analytics, a parcel registration form, a status update table (Transit/Done), and a public tracking page for customers.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** PHP (Procedural)
- **Database:** MySQL (via XAMPP)
- **Version Control:** Git & GitHub

## Key Features
- **Secure Admin Login:** Role-based access control protecting admin routes.
- **Dashboard Analytics:** Live counting of Total, In Transit, and Delivered parcels with a dynamic bar chart.
- **Full CRUD Operations:** Admins can Create, Read, Update (Transit/Done), and Delete parcels.
- **Public Tracking:** Customers can search for their parcels using a unique tracking code without logging in.
- **Responsive Dark UI:** A modern dark/teal theme built from scratch.
